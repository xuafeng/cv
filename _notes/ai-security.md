AI for security has been a long-running thread in my work, from NLP-assisted IoT security research to LLM-powered workflows for modern defensive operations.

Recent directions include:

+ asset discovery and rule generation;
+ bot detection for large-scale online services;
+ open-source intelligence processing and threat intelligence reports;
+ static analysis for memory-related vulnerabilities;
+ secure generation of scripts such as PowerShell.

The practical challenge is to turn model capability into reliable security workflows that analysts and product teams can trust.
