Future agent systems are AI systems that can use tools, handle context, coordinate steps, and improve real workflows under production constraints.

My interest is in the full lifecycle:

+ benchmark the right tasks and failure modes;
+ build agents with the right tools, context, prompts, code, and model choices;
+ evaluate behavior with representative workloads;
+ orchestrate many agents for many users;
+ keep the system evolving as tasks, tools, and models change.

The central question is how to make agents dependable enough for real work while preserving the flexibility that makes them useful.
