System intelligence asks what it would take for AI to design, implement, operate, and maintain computing systems rather than only produce fragments of code.

The hard parts are not only syntax or local correctness. Real systems require architecture, constraints, cost models, observability, failure handling, security boundaries, and judgment about which trade-offs will still make sense later.

Current threads:

+ defining representative benchmarks and tasks;
+ studying how agents reason across code, documents, runtime behavior, and operational constraints;
+ building systems that can improve through evaluation rather than one-off prompting;
+ connecting research prototypes to production engineering needs.

See the project page at [sys-intelligence.github.io](https://sys-intelligence.github.io/).
